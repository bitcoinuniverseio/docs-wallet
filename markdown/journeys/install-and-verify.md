# Install and verify the authentic extension
 About 10 minutes Check before you act Wallet 1.7.5.8 · unpublished 
 Outcome: The wallet is installed from a real source and you know how to check it.
 Before you start: A Chrome-family browser
 Completion looks like: The extension is installed from the Chrome Web Store listing and its version is known.
 If something goes wrong: An extension can be removed in the browser's extensions page at any time. Installation changes nothing on chain.
 
 
## All steps
 
- 
### Open the official store listing
 You are trying to Install from the publisher's listing, not a copy. You should see The Chrome Web Store opens on the Universe Wallet listing. You do Use the install link from this site's install page or the official site. Check the publisher name. Before you continue, check The publisher and item identifier match the official site. Fake wallets live on near-identical URLs. What can go wrong A listing with a different publisher, or any direct ZIP from chat or search ads, is the classic phishing pattern. Reversible? Yes. 
- 
### Add the extension
 You are trying to Complete the browser install. You should see The browser asks to confirm adding the extension. You do Confirm. Pin the icon if you want it visible. Before you continue, check Only the permissions the browser shows should appear. Nothing here should ask for your recovery phrase. What can go wrong No real wallet ever asks for existing recovery words during install. A page that does is an impostor. Reversible? Yes. 
- 
### Verify what you installed
 You are trying to Know the version you actually have. You should see The wallet opens on its welcome or unlock screen. You do Open settings and read the version, or use Detect my wallet here. Before you continue, check You know the version and which parts of this site describe it. What can go wrong If the wallet fails to open, remove it and reinstall from the listing; do not hunt for the missing wallet on search engines. Reversible? Yes. 

 Something wrong on this page? Open a prefilled issue in the documentation repository. What travels: the page path, the release this site describes, and your own words. Nothing about your wallet, transactions, or this browser is included or stored by this site.

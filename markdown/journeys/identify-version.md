## All steps
 
- 
### Open the wallet and its settings
 You are trying to Reach the wallet's About or Settings area, where the version is shown. You should see The wallet opens. Settings lists backup status, security, and About entries. You do Click the wallet icon, then open Settings. Before you continue, check You can see the settings list. If the wallet asks for a password, that is the unlock screen, not settings; unlock first. What can go wrong If no wallet icon exists in the browser, the extension is not installed. That is a different journey. Reversible? Yes. 
- 
### Read the version number
 You are trying to Find the exact version string. You should see A version like 1.0.13 or 1.7.5.8 is displayed. You do Open About (or the version row) and note the number. Before you continue, check You wrote down the exact version, not a date or a build channel. What can go wrong Some builds show the version only in the extension's detail page (browser extensions page). Both numbers are the same. Reversible? Yes. Branch: Version 1.0.13 is the published store build from April 2025. Screens on this site may not exist in it.
 
- 
### Or use Detect my wallet
 You are trying to Let this site read the version for you without you touching settings. You should see The header control reports the detected version, or says none was found. You do Click 'Detect my wallet' in this site's header. Only the version is read. Before you continue, check The control names exactly what was detected and never asks for accounts or addresses. What can go wrong An unknown version is labeled unknown. This site never guesses the nearest release. Reversible? Yes.

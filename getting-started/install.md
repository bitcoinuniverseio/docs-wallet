# Install Universe Wallet

This page gets the extension installed and pinned so the rest of setup is one click away.

## Before you start

- A Chromium browser (Chrome 88 or newer, or a compatible browser such as Brave or Edge).
- Two minutes.

## Steps

1. Open [Universe Bitcoin Wallet on the Chrome Web Store](https://chromewebstore.google.com/detail/universe-bitcoin-wallet/fjalkkkbjffhgdoheannkodafhemfdba).
2. Check the listing before installing. The name is **Universe Bitcoin Wallet** and the publisher is **Universe**. If either differs, stop: you are on a copycat listing.
3. Select **Add to Chrome** and confirm.
4. Pin the extension: select the puzzle-piece icon in the toolbar, then the pin next to Universe. The wallet opens as a popup; you can also open it as a side panel or a full tab later.

## What success looks like

The Universe icon sits in your toolbar. Opening it shows **Welcome to Universe** with three choices: **Create new wallet**, **I already have a wallet**, and **Connect to Hardware Wallet**.

## Permissions the extension asks for

The extension requests only what its features need:

- **Storage**: keeps your encrypted vault and settings on your device.
- **Active tab and site access**: lets a site you visit request a connection, which you approve or reject in the wallet.
- **Side panel**: lets the wallet open beside the page instead of as a popup.
- **Network request rules**: blocks known phishing domains before they load.

The extension never asks for your recovery phrase during install. Nothing before wallet creation should ask you to type secret words.

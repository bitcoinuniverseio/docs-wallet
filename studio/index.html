Developer Integration Studio

Developer Integration Studio

Everything here is generated from the wallet's real provider surface - 45 methods, 6 events, namespaces tapwallet, tap_wallet, TapWallet, tapWallet, Tap_Wallet, universe, universewallet, UniverseWallet, bitcoinuniverse, bitcoinUniverse. The default playground runs a fake provider built from the contract: it reproduces shapes, events, and documented errors without contacting any wallet or network.

This release authorizes 0 of 42 protocols. The simulation reproduces those refusals faithfully: methods whose protocol operation is unauthorized answer with the same error the real wallet gives, so your unavailable states get built against the truth.

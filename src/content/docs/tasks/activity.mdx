**Intended reader:** anyone checking a payment or a saved product request.
**Goal:** establish what happened before starting another request.
**Prerequisites:** an unlocked wallet and the account used for the original request.
**Chain and network:** select the original account and exact network.
**Safety:** an unknown outcome can include a payment that was accepted. Do not create a replacement
request merely because the popup closed or a response timed out.

This page describes the current source candidate. It does not establish that the candidate is
published or that a payment feature is available in your build. See
[What this release authorizes](/docs-wallet/assets/support-state).

## Steps

1. Open **Activity** to inspect chain transactions for the selected account.
2. For a saved product request, return to the screen where you created it. Screens using the shared
   request panel restore the latest unresolved request for that product, operation, account and network.
3. Compare the displayed operation identifier with the request you are checking.
4. If the panel offers **Check status**, use it to ask for the existing request's result.
5. If preparation was not acknowledged and **Retry same request** appears, use that control to retain
   the original request identity.
6. Approve a restored review only after checking its account, network, amounts, destination and expiry.
   A saved review has not yet authorized a payment.

## What the request panel means

| Display | Meaning | Next step |
| --- | --- | --- |
| Review request | The request is saved and awaits approval | Check the terms; approve or cancel |
| Submission in progress | The approved operation started | Keep the identifier and check status |
| Submitted. Waiting for settlement | Submission was recorded; settlement is unconfirmed | Check status |
| Outcome unknown | Available evidence cannot establish the outcome | Check this request before trying again |
| Settled | The configured authority verified the result | Inspect the recorded result and reference |
| Payment instruction parsed | Local parsing completed; no payment was submitted | Review the parsed instruction |
| Payment request saved. Awaiting payment | A receiving request was created | Wait for separately verified payment evidence |
| Cancelled before dispatch | Cancellation was saved before submission | Start another request only if needed |

An operation identifier, a transaction identifier, an invoice, a QR code or a successful HTTP response
is not proof of settlement. A failure message alone does not prove that no funds moved or no fee was
paid. Use the recorded evidence for that request.

## Expected result and verification

Checking status keeps the same operation identifier. Closing the popup does not cancel a submitted
operation. A restored review retains its original expiry; reopening the screen does not extend it.

Chain activity and product requests describe different stages. A transaction in a mempool is still
unconfirmed, and chain inclusion can later change after a reorganization. Asset indexers may lag
behind the chain, so a confirmation alone does not establish that an asset was delivered.

## Common failures and recovery

| What you see | What to do |
| --- | --- |
| No request after changing accounts or networks | Select the account and exact network used originally |
| Review expired or approval became stale | Recheck the terms and current account before requesting a new review |
| History or storage is unavailable | Preserve the existing wallet data and retry the read; an error is not empty history |
| Outcome remains unknown | Keep the operation identifier and any public reference for support; do not submit another payment |
| Confirmed transaction but missing asset effect | Check the protocol's availability and indexer status |

Do not clear extension data to repair a pending operation. If status cannot be established, use
[support](/docs-wallet/help/support). Share public operation references only, never keys, recovery
phrases, connection credentials or signed transaction bytes.
